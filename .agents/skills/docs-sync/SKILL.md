# Documentation sync skill

1. Read `agents/documentation-agent.md`, `docs/PROJECT.md`, `docs/PLAN.md`, `docs/PROGRESS.md`.
2. Identify changed APIs, scene ownership or research assumptions from source diff/validated tests.
3. Update architecture and feature schema before or together with implementation changes.
4. Change milestone checklist only with evidence; record tests, blockers and next actions in `docs/PROGRESS.md`.
5. For consequential decisions add a short dated ADR in `docs/decisions/`.
6. Include verifiable primary links; distinguish GDC 2016 presentation from ACM 2020 paper.
